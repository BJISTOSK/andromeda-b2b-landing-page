Convex Backend Architecture

How BOS Interfaces with Convex

1. Schema-Gated Queries

Telemetry is defined in convex/schema.ts with tables for bos_operations, bos_tasks, and bos_metrics.

2. Reactive WebSocket Subscriptions

Mutations executed in convex/bos.ts instantly broadcast state changes to all connected enterprise clients without polling.

3. Isolated Static Delivery

The BOS front-end compiles to static HTML/CSS/JS via Astro and deploys to Cloudflare Pages edge CDN, eliminating server bottlenecks.
